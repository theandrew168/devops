# victoria_logs
Ansible role for installing and configuring [VictoriaLogs](https://docs.victoriametrics.com/victorialogs/)

## Configuration
| Variable | Default | Description |
| -------- | ------- | ----------- |
| `victoria_logs_version` | `v1.52.0` | Version of victoria logs to install |
| `victoria_logs_data_dir` | `~` | Directory to hold victoria logs data |
